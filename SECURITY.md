# Security policy

## Supported versions

MELvan is pre-1.0. Security fixes are applied to the latest released version;
older development snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to `mills.martin@gmail.com`.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not include real program data, credentials, or exploit activity
against systems you do not own.

You should receive an acknowledgement within seven calendar days. Please avoid
public disclosure until the report has been assessed and a reasonable
remediation or disclosure timeline has been agreed.
